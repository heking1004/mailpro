## 功能特性

### 发送能力
- 支持 QQ / 163 / Gmail / Outlook / Hotmail 多平台 SMTP
- 多发件人池轮询或随机策略，分散单账号压力
- BCC 密送分组模式，一次事务发送多人，大幅提升效率
- 发送间隔随机化，模拟自然发送行为
- 发送前确认弹窗，防止误操作

### 模板个性化
- `{{name}}` — 收件人邮箱前缀
- `{{email}}` — 完整邮箱地址
- `{{domain}}` — 邮箱域名
- `{{greeting}}` — 随机问候语（你好 / Hi / Hello 等）
- `{{closing}}` — 随机结尾语（祝好 / Best regards 等）
- `{{date}}` — 当前日期
- `{{time}}` — 当前时间
- `{{random}}` — 零宽隐形字符，让每封邮件哈希不同

主题和正文均支持模板变量。

### 反垃圾 & 提升投递率
- 完整邮件头：Message-ID、Date、MIME-Version、Reply-To
- List-Unsubscribe 退订头（RFC 8058），Gmail/Outlook 显示退订按钮
- 单发件人冷却机制（最小 5 秒间隔）
- 自适应降速：检测到限频错误自动扩大间隔
- 新发件人预热：前 10 封使用加长间隔，避免触发风控
- 零宽字符差异化：每封邮件内容哈希唯一

### 安全防护
- 每日发送上限：每个发件人独立配置
- 硬退信自动记录，下次自动跳过无效地址
- 收件人去重
- 邮箱预验证：格式检查 + 域名 DNS 解析
- 发件人连接测试
- 在线激活码验证，可远程控制

### 工具功能
- 从 TXT/CSV 文件导入收件人
- 收件人实时计数
- 发送进度条 + 实时日志
- 发送结果导出（CSV）
- 日志导出
- 发件人管理：添加 / 删除 / 测试

### 界面
- Termius Dark 风格暗色主题
- 自定义模态弹窗
- 侧边栏导航

## 使用提示

1. 首次运行输入激活码
2. 在「发件人」页面添加 SMTP 发件人（需要邮箱授权码）
3. 在「发送邮件」页面输入收件人、主题、正文
4. 选择发送策略和模式，点击发送

## 注意事项

- 请合理使用，遵守相关法律法规
- 建议配置退订链接，降低被投诉风险
- 新发件人建议先少量发送，逐步提升日发送量
- 批量发送前建议先验证收件人有效性
